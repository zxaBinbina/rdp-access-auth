连接信息

填写浏览器访问的域名，不含 https://。更换域名后，需要同步 Tunnel 配置并重新绑定通行密钥。

访问凭据

已有 Token 会自动填入，点击眼睛可查看。需要更换时直接修改。

固定密码已设置

当前密码继续有效，无需重复填写。

固定密码只保存校验哈希，无法查看原文。新密码需为 16～128 位，包含大小写字母、数字和特殊符号；更换不会重置临时密码或通行密钥。

人机验证

已有密钥会自动填入，点击眼睛可查看 Secret key。首次启用时填写 Cloudflare 组件的密钥；关闭此开关会清除它们。

当前未启用人机验证。固定密码、临时密码和通行密钥均可正常使用。

高级配置
