连接与认证

直接读取 frpc TOML，自动提取 Token 和 TCP 代理。Token 不会显示在页面。

API 隧道 ID 不在标准 frpc TOML 中，请按 SakuraFrp 控制台填写。

16～128 位，包含大小写字母、数字和特殊符号。

Cloudflare Tunnel

在 Cloudflare 控制台创建 Tunnel 后，复制安装命令中的 Token 部分。无需填写 Cloudflare 账户密码或全局 API Key。

请在该 Tunnel 添加公开域名路由：认证域名 → http://127.0.0.1:18089。

可选：Turnstile 与已有词库

安装包不包含游戏词库，首次部署会从公开来源下载。也可指定通过项目工具生成的词库。

此步骤只准备文件，不写入系统。
