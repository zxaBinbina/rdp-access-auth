# 2.0 产品需求与交付范围

以下为 2026-10-31 至 2026-11-01 逐项确认的需求。实现时不得用演示数据或占位操作替代实际功能。

## 产品范围

- 统一管理访问认证、SakuraFrp 客户端和 Cloudflare Tunnel。
- 不接管 KDE 远程桌面的安装与日常设置；检测到已安装 KRDP 时，应用适用于对应版本的已有修复补丁。
- 首版支持 Fedora、Debian / Ubuntu，优先 KDE 桌面。
- 保留 1.x 的全部功能和安全规则，包括固定密码、Passkey、已有三词临时密码、密码轮换、访问期限、封禁、Turnstile、可信来源 IP、本机准入、凭据管理、迁移和日志。
- 客户端管理页面使用独立 WebView 桌面窗口，应用启动器可启动主程序，不再用外部浏览器打开本机管理页面。
- 公网认证页面继续供远程访问者通过浏览器使用。

## 桌面交互和服务生命周期

- 提供系统托盘图标，菜单有打开设置、暂停 / 继续、重启服务、退出。
- 设置中允许隐藏托盘图标；隐藏不会停止服务，仍可从应用启动器打开设置。
- 关闭主窗口仅收起窗口，不退出服务。
- 明确点击退出时，弹窗说明会停止认证、frp 和 Cloudflare 隧道，确认后关闭管理程序并停止这三类服务。
- 退出弹窗提供“下次开机不自启动”选项；未选择时允许下次开机自动恢复。
- 默认系统开机即启动服务，不依赖桌面登录；设置中可切换为登录桌面后启动或手动启动。
- 暂停会停止全部上述服务，并中断经 frp 建立的连接；暂停状态跨系统重启保持，直到用户手动继续。
- 不因开启设置窗口、隐藏托盘、管理窗口崩溃而意外修改暂停状态。

## 首次使用向导

- 配置向导使用独立布局，仅在尚未完成首次配置时显示；不作为主界面侧栏项目。配置完成后进入主界面，后续启动不再显示向导。
- 欢迎页之后先设置配色和明暗模式，再配置管理账户。外观选择立即预览，创建或解锁管理账户后保存。
- 配置向导不显示锁定或解锁按钮；移除配置帮助按钮及原帮助弹窗。主界面的使用说明链接到项目文档。
- 演示模式可通过演示控制栏切换主界面与配置向导；公网认证页预览仅在演示模式的主界面提供。普通管理环境不显示该预览项目。
- 面向从未部署过的新用户：欢迎、准备账号与域名、获取 API 密钥、选择 / 创建隧道、设置密码、检查连接、完成。
- 支持手动配置和 API 自动配置，推荐自动配置；平台账号注册和域名购买仍由用户在平台完成。
- 自动配置实际调用 SakuraFrp / Cloudflare API，展示选项和错误，记录已创建资源，防止重试时重复创建。
- 手动配置提供逐步教程、平台入口、字段说明和校验，不要求用户先理解内部实现。
- 支持交给外部 Agent 部署，提供本机 MCP 接入信息及可复制的部署说明。
- 完成安装后由用户亲自从头运行向导，不预填开发者的真实凭据或替用户完成真实线上部署。

## 本机安全与 Agent

- 只提供本机 MCP 接口；通过 SSH 在本机执行的 Agent 属于本机调用。不提供远程网络管理接口。
- Agent 使用已登记身份；授权绑定身份，可跨任务复用，普通修改的授权期为批准后的固定 1 小时。
- 初次 / 到期后的修改需用户批准。用户可以在图形窗口批准，或在独立终端输入管理密码批准。
- 普通配置、API 密钥、远程访问密码和服务操作在已授权时段内无需重复批准。
- 修改管理密码、修改 Agent 授权规则属于危险操作，始终单独确认，不能被普通 1 小时授权绕过。
- 本机用户无需密码即可查看状态；修改前用独立管理密码解锁，授权限于当前管理窗口会话。
- 关闭管理窗口后会话重新锁定；危险操作始终保留单独确认。
- 接口不默认返回密钥原文；日志、报错、进程命令行、导出的诊断不泄露密码或 Token。
- 应能查看已登记 Agent、剩余授权时间和操作记录，撤销授权立即生效。
- 操作由受保护的本机控制服务执行；不能仅靠前端隐藏按钮或 Agent 自报名称实现权限。

## 视觉规范

- 界面使用正式的软件术语和操作说明，不显示宣传标语、设计来源或与操作无关的说明。
- 演示窗口注册系统托盘图标，注明演示模式；托盘操作仅改变内存中的演示状态。
- 依据 `/home/zxabinbina/桌面/Project/homepage/DESIGN.md` 与其当前源码。
- 配色使用芙芙蓝（默认）与胡桃红；每套有深 / 浅模式，共四种组合。
- 配色与明暗独立设置；明暗提供跟随系统、固定浅色、固定深色，保存选择并避免首帧闪烁。
- 统一更新本机管理窗口、欢迎向导、授权窗口与公网认证页面。
- 沿用语义色、圆角面板、细边框、胶囊按钮、Lucide 图标、字体回退栈、克制动效和减少动态效果支持。
- 根据桌面管理和表单阅读需求调整布局与字号，不照搬主页长页面的空间尺寸。

## 交付与验证

- 其他发行版的构建与测试优先使用 GitHub Workflow；不在本机下载其他系统容器。
- 提供匹配目标发行版运行时的 RPM / DEB，安装后在应用启动器出现可用入口。
- 在隔离环境验证安装、首次启动、卸载和服务状态，不重新部署用户刚清理的真实认证 / frp 服务。
- 保留既有认证测试，并补充 MCP 身份隔离、授权过期、危险操作、持久暂停、代理接口和桌面窗口的行为验证。
- 外部平台使用可重复的协议测试与错误路径验证；真实账号端到端验收通过用户首次向导完成，报告中明确区分。
- 文档提供新用户安装指南、MCP 接入、维护和卸载说明。
